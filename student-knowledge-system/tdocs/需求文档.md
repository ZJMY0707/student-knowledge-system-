# 学生个人知识库与日程标注系统 – 需求分析与设计文档

## 1. 项目描述

### 1.1 项目背景
在信息化学习环境中，学生经常面临学习笔记分散、任务计划混乱的问题。本项目旨在开发一套**个人知识库与日程标注系统**，帮助学生统一管理学习资料（知识条目）与学习计划（日程任务），并通过可视化统计了解学习效率。

### 1.2 项目目标
- 提供知识条目的增删改查及分类/标签管理
- 提供学习日程的增删改查与状态跟踪（待开始、进行中、已完成、逾期）
- 实现用户角色管理（普通学生、管理员）
- 提供数据统计与图表展示
- 前后端分离，JavaFX 作客户端，Spring Boot 3 作服务端

### 1.3 业务范围
- 个人知识库管理
- 日程任务管理
- 基础的用户认证与授权
- 系统数据统计展示

- **二级菜单导航**：左侧菜单栏，第一级为模块（知识库、日程、统计），第二级为子功能（我的笔记、分类管理；我的日程、已完成任务等）。

- **工作空间切换**：主内容区通过选项卡/不同视图切换不同功能模块。

### 2.3 基本信息维护（20分）——至少4个模块

| 模块             | 功能说明                                                     | 核心数据操作               |
|------------------|--------------------------------------------------------------|----------------------------|

### 2.4 复杂业务流程（15分）

1. **多表关系设计**  
   - 知识条目 ↔ 分类：多对一（一个分类下有多条笔记，一条笔记属于一个分类）  
   - 知识条目 ↔ 标签：多对多（通过中间表 `t_entry_tag` 实现）  
   - 日程任务与知识条目可建立弱关联（一个任务可关联一条笔记，便于快速查看笔记内容）

2. **状态管理**  
   - 日程任务状态流转：待开始 → 进行中 → 已完成（若超时未完成且截止时间 < 当前时间，自动标记为“逾期”）。  
   - 前端提供状态变更按钮，后端校验状态变更合法性。

3. **单一复杂界面**  
   - 知识条目编辑界面集成：富文本编辑器（如 RichTextFX 或 JavaFX WebView 的 HTML 编辑）、多选标签下拉框、分类下拉选择、实时预览。

4. **多界面集成功能**  
   - 在日程任务列表中，点击某任务的“关联笔记”按钮，可跳转到该知识条目的查看/编辑界面；  
   - 在知识条目详情页，提供“添加到今日计划”快捷按钮，生成一条新日程任务。

## 3. 非功能性需求（对应质量要求20分）

### 3.1 用户体验（7分）
- **界面布局协调**：统一使用 CSS 美化，字体/间距一致，支持窗口缩放自适应
- **导航便捷**：菜单点击即切换，提供面包屑导航
- **操作流畅**：网络请求异步执行（使用 `javafx.concurrent.Task`），避免 UI 卡顿
- **组件多样性**：使用文本框、日期选择器、下拉框、单选/复选、表格视图、卡片布局等

### 3.2 程序质量（10分）
- **输入校验（前端+后端）**：
  - 必填字段（如标题、分类）非空校验
  - 数值/文本类型限制（如优先级 1-3）
  - 日期格式校验（截止时间不能早于当前日期）
- **异常处理**：
  - 网络请求失败弹窗提示，不崩溃
  - 后端统一异常处理（`@RestControllerAdvice`），返回标准错误 JSON
  - 前端捕获异常后显示友好提示
- **会话管理**：
  - JWT Token 存储在内存（或安全存储），每次请求放入 `Authorization` 头
  - Token 过期时自动跳转登录页并清空本地数据

### 3.3 部署运行（3分）
- 后端可打包为 `java-server.jar`，使用 `java -jar` 运行，默认端口 `8080`
- 前端打包为 `java-fx.jar`，内嵌启动类，连接后端 URL 可通过配置文件或启动参数指定
- 提供 `start-server.bat/sh` 和 `start-client.bat/sh` 脚本
- 交付件包含：源码压缩包、可执行 jar、系统演示视频（含功能展示）

## 4. 数据设计（10分）

```
User（用户）1──n KnowledgeEntry（知识条目）
```

## 5. 系统架构

### 5.1 物理架构
- **前端**：JavaFX 客户端（MVC模式），通过 HTTP 调用 RESTful API
- **后端**：Spring Boot 3（Controller → Service → Repository），使用 Spring Data JPA
- **数据库**：MySQL 8.0 或 H2（开发/测试）
- **通信**：JSON over HTTP，JWT 认证

### 5.2 逻辑架构图（简述）

```
[JavaFX Client]  <--->  [Spring Boot Server]  <--->  [MySQL]
      |                      |
   View/Controller      Controller/Service
      |                      |
   Service (HTTP)        Repository (JPA)
```

### 5.3 后端主要包结构
- `studentknowledge.controller`：REST API 接口
- `studentknowledge.service`：业务逻辑
- `studentknowledge.repository`：数据访问
- `studentknowledge.model.entity`：JPA 实体
- `studentknowledge.model.dto`：数据传输对象（避免直接暴露实体）
- `studentknowledge.security`：JWT 过滤器、配置
- `studentknowledge.exception`：全局异常处理

### 5.4 前端主要包结构
- `studentknowledge.client.controller`：界面控制器（每个 FXML 对应一个 Controller）
- `studentknowledge.client.service`：HTTP 调用服务（使用 HttpClient 或 OkHttp）
- `studentknowledge.client.model`：与后端 DTO 对应的普通 Java 对象

## 6. 关键接口设计示例（RESTful）

| 功能           | 方法 | URL                          | 请求体（示例）                         | 响应                       |
|----------------|------|------------------------------|----------------------------------------|----------------------------|
| 用户登录       | POST | /api/auth/login              | `{"username":"S001","password":"123"}` | `{"token":"...","role":"STUDENT"}` |
| 查询我的笔记   | GET  | /api/entries?page=0&size=10  | 无                                     | 分页的笔记列表             |
| 新增笔记       | POST | /api/entries                 | `{"title":"笔记","content":"..." , "categoryId":1, "tagIds":[2,3]}` | 创建的笔记对象 |
| 更新任务状态   | PUT  | /api/tasks/{id}/status       | `{"status":"COMPLETED"}`               | 更新后的任务               |
| 按分类统计笔记 | GET  | /api/statistics/notes-by-category | 无                                 | `[{"category":"Java","count":5}, ...]` |

> 所有需要认证的接口统一在 Header 中携带 `Authorization: Bearer <token>`。

## 7. 系统实现要点（体现技术先进性）

1. **前后端分离**：JavaFX 通过 HTTP 调用后端，便于独立开发和部署。
2. **JWT 无状态认证**：支持多端扩展，Token 中存储用户角色信息。
3. **富文本编辑**：采用 `RichTextFX` 或内嵌 `WebView` 编辑 HTML 内容，提升知识编辑体验。
4. **图表可视化**：后端提供聚合数据，前端用 `JavaFX Charts` 或 `JFreeChart` 渲染。
5. **自动逾期状态更新**：每日首次登录或定时任务将截止时间已过且未完成的任务状态置为 `OVERDUE`。
6. **输入校验双重保障**：前端即时校验提示 + 后端 `@Valid` 校验，保证数据完整性。
